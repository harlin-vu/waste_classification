# Waste Image Classification using Deep Learning

Computer Vision | Deep Learning | Image Classification | Python

## Overview

Efficient waste sorting is essential for improving recycling processes and reducing environmental impact. This project explores the use of deep learning techniques to automatically classify waste images into multiple recyclable categories.

Different Artificial Neural Network (ANN) and Convolutional Neural Network (CNN) architectures were developed and evaluated to determine the most effective approach for image classification.

---

## Business Objectives

- Develop an automated waste classification model.
- Compare ANN and CNN architectures for image recognition.
- Improve classification efficiency for recycling applications.
- Demonstrate the application of computer vision to sustainability challenges.

---

## Methodology

The project followed a complete deep learning workflow:

- Image preprocessing
- Data normalisation
- Label encoding
- Model development
- Performance evaluation
- Model comparison

Image preprocessing included resizing, normalisation, and train-test splitting to prepare the dataset for deep learning models.

---

## Model Development

Multiple deep learning models were designed and evaluated, including:

- Artificial Neural Networks (ANN)
- Convolutional Neural Networks (CNN)

Different model architectures were explored by varying:

- Network depth
- Convolutional layers
- Optimisation strategies
- Dropout techniques
- Regularisation methods

Models were evaluated using classification metrics, including accuracy, precision, recall, F1-score, and Cohen's Kappa.

---

## Key Outcomes

The project demonstrates that:

- Convolutional Neural Networks significantly outperform traditional Artificial Neural Networks for image classification tasks.
- Appropriate preprocessing and model design improve classification performance.
- Well-designed CNN architectures provide stronger generalisation and reduce overfitting.
- Visually similar waste categories remain challenging and require further improvements in dataset quality and model robustness.
